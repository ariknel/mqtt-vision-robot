================================================================================
 MQTT VISION ROBOT — BUILD & FLASH GUIDE
================================================================================

This project uses Docker Desktop for building and WSL2 Ubuntu for flashing.
ESP-IDF version: 5.4.1

================================================================================
 WINDOWS
================================================================================

--------------------------------------------------------------------------------
 ONE-TIME SETUP
--------------------------------------------------------------------------------

1. Install Docker Desktop
   https://www.docker.com/products/docker-desktop

2. Install WSL2 with Ubuntu
   Open PowerShell as Administrator:
     wsl --install -d Ubuntu
   Follow prompts to create username and password.
   Close and reopen terminal when done.

3. Install usbipd (PowerShell as Administrator):
     winget install usbipd

4. Install esptool inside WSL2 (NOT on Windows):
   Open Ubuntu terminal (Windows Terminal → Ubuntu tab):
     sudo apt update
     sudo apt install pipx -y
     pipx install esptool
     pipx ensurepath
     source ~/.bashrc

5. Add user to dialout group (WSL2 Ubuntu terminal):
     sudo usermod -aG dialout $USER

--------------------------------------------------------------------------------
 BUILD (every time)
--------------------------------------------------------------------------------

1. Open Docker Desktop — make sure Engine is running
2. Open VS Code → open mqttvision folder
3. Ctrl+Shift+P → Dev Containers: Reopen in Container
4. Open integrated terminal (Ctrl+`)
5. Build:
     cd /project/firmware
     idf.py build

--------------------------------------------------------------------------------
 FLASH (every time)
--------------------------------------------------------------------------------

Step 1 — Attach ESP32 to WSL2
  Open PowerShell as Administrator:
    usbipd list
    (find "Silicon Labs CP210x" or "CH340", note BUSID e.g. 1-8)
    usbipd bind --busid 1-8
    usbipd attach --wsl --busid 1-8

  NOTE: Run this every time you unplug/replug the ESP32.
  NOTE: BUSID may change if you use a different USB port.

Step 2 — Fix USB permissions (if first time or permission denied)
  Open Ubuntu terminal:
    sudo chmod 666 /dev/ttyUSB0

Step 3 — Flash
  Open Ubuntu terminal:
    cd /mnt/c/Users/Arik/Desktop/mqttvision/firmware/build
    esptool.py --chip esp32 -p /dev/ttyUSB0 -b 460800 --before default_reset --after hard_reset write_flash @flash_args

Step 4 — Monitor serial output
    screen /dev/ttyUSB0 115200
    (exit with Ctrl+A then K)

--------------------------------------------------------------------------------
 TROUBLESHOOTING — WINDOWS
--------------------------------------------------------------------------------

PROBLEM: esptool.py command not found
  FIX: pipx ensurepath && source ~/.bashrc

PROBLEM: No such file or directory: 'bootloader/bootloader.bin'
  FIX: You must cd into the build folder first:
    cd /mnt/c/Users/Arik/Desktop/mqttvision/firmware/build
    then run the flash command

PROBLEM: Permission denied on /dev/ttyUSB0
  FIX: sudo chmod 666 /dev/ttyUSB0
  PERMANENT FIX: sudo usermod -aG dialout $USER (then reopen terminal)

PROBLEM: /dev/ttyUSB0 not found
  FIX 1: Run usbipd attach again in PowerShell as Admin
  FIX 2: Try /dev/ttyUSB1 instead
  FIX 3: Unplug and replug ESP32, run usbipd attach again

PROBLEM: idf.py command not found in container
  FIX: source /opt/esp/idf/export.sh
  PERMANENT: already in .bashrc via devcontainer onCreateCommand

PROBLEM: Docker container won't start
  FIX: Make sure Docker Desktop is running first, then reopen in container

================================================================================
 ARCH LINUX
================================================================================

Arch is the easiest setup — everything runs natively, no Docker or WSL needed.

--------------------------------------------------------------------------------
 ONE-TIME SETUP
--------------------------------------------------------------------------------

1. Install dependencies:
     sudo pacman -S git cmake ninja python python-pip python-pipx

2. Add user to uucp group for USB access:
     sudo usermod -aG uucp $USER
   Log out and back in for this to take effect.

3. Install ESP-IDF:
     git clone --recursive https://github.com/espressif/esp-idf.git ~/esp/idf
     cd ~/esp/idf
     git checkout v5.4.1
     ./install.sh esp32

4. Add to shell profile so IDF is always available:
     echo 'source ~/esp/idf/export.sh' >> ~/.bashrc
     source ~/.bashrc

5. Verify:
     idf.py --version
     (should show ESP-IDF v5.4.1)

--------------------------------------------------------------------------------
 BUILD
--------------------------------------------------------------------------------

   cd ~/path/to/mqttvision/firmware
   idf.py build

--------------------------------------------------------------------------------
 FLASH
--------------------------------------------------------------------------------

   Plug in ESP32, then:
     idf.py -p /dev/ttyUSB0 flash monitor

   If permission denied:
     sudo chmod 666 /dev/ttyUSB0
     (permanent fix: sudo usermod -aG uucp $USER then log out/in)

   If port not found, check which port appeared:
     ls /dev/tty* (unplug ESP32, run, plug back in, run again — new entry is your port)

--------------------------------------------------------------------------------
 TROUBLESHOOTING — ARCH
--------------------------------------------------------------------------------

PROBLEM: idf.py not found after reboot
  FIX: source ~/esp/idf/export.sh
  (should be automatic if you added it to ~/.bashrc)

PROBLEM: Permission denied on /dev/ttyUSB0
  FIX: sudo chmod 666 /dev/ttyUSB0
  PERMANENT: sudo usermod -aG uucp $USER then log out and back in

PROBLEM: Port is /dev/ttyACM0 not /dev/ttyUSB0
  FIX: idf.py -p /dev/ttyACM0 flash monitor

================================================================================
 TRANSFERRING BETWEEN MACHINES
================================================================================

   git push     (from current machine after changes)
   git pull     (on other machine)
   idf.py fullclean   (always clean before first build on new machine)
   idf.py build

   Never commit the build/ folder — it is in .gitignore

================================================================================
 USEFUL COMMANDS
================================================================================

   idf.py build                      compile firmware
   idf.py fullclean                  wipe build folder completely
   idf.py menuconfig                 configure ESP32 settings (GUI)
   idf.py size                       show binary size breakdown
   idf.py -p /dev/ttyUSB0 monitor    serial monitor only (no flash)
   idf.py -p /dev/ttyUSB0 flash monitor   flash and monitor in one command
